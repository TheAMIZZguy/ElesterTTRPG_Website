# Elester — Martial Feats (Practical v3)

This pack is the **practical** martial tree version:
- No “feat to unlock feats” gate.
- Proficiencies are **repeatable choose-a-group feats** (no per-group-per-tier spam).
- Only **active / exception** tech is gated behind feats (actions, reactions, conversions).
- Maneuvers are the main build identity, with mini-trees.

Weapon Groups: Bladed, Brawling, Flexible, Impact, Ranged, Shield, Sweeping, Throwing, Thrusting
Armour Groups: Cloth, Composite, Leather, Steel, Wood
Fields: Life, Death, Earth, Blight, Flow, Static, Fire, Ice
