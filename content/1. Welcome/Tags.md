## Other

### Conditions

| Tag         | Meaning                                            |
| ----------- | -------------------------------------------------- |
| #Condition  | All conditions carry this                          |
| #Mental     | Affects mind, will, or social behaviour            |
| #Physical   | Affects body, strength, or movement capability     |
| #Aetherical | Affects field connection or aetherical ability     |
| #Sense      | Affects a specific sensory faculty                 |
| #Detection  | Affects how you are perceived or located by others |
| #Movement   | Restricts or alters physical movement              |
| #Actions    | Modifies AP, action count, or action availability  |
| #Rest       | Represents fatigue and rest state                  |
| #Death      | Relates to dying, VP, or mortality                 |
| #Relation   | Represents attitude toward a creature              |
| #Object     | Applies to inanimate objects rather than creatures |
| #Tiered     | Condition includes a numeric value that scales     |


## Maxems

### Weave Tags

| Tag       | Meaning                                                             | Weaves                                                   |
| --------- | ------------------------------------------------------------------- | -------------------------------------------------------- |
| #Delivery | Defines how and where the manifold reaches its target               | Touch, Direct, Area, Range                               |
| #Geometry | Modifies the shape or coverage of a Delivery weave                  | Geometric Exclusion, Advanced Area                       |
| #Output   | Modifies the potency, dice, or result of the manifold's effect      | Augment, Heighten, Enhanced, Raise Floor, Wild Potential |
| #Tempo    | Modifies the timing, speed, duration, or deployment of the manifold | Quicken, Duration, Hold, Trigger, Echo, Sustain          |
| #Economy  | Modifies the MP cost of the evocation, up or down                   | Conserve, Unstable                                       |
| #Risk     | Carries a chance of negative consequence for the caster             | Overcharge, Unstable                                     |
| #Warding  | Protects the manifold against interference or counter-evokes        | Anchor                                                   |

### Manifold Tags

| Tag            | Meaning                                                  |
| -------------- | -------------------------------------------------------- |
| #Attack        | Requires an attack roll vs a Defence                     |
| #Automatic     | No roll required — effect applies on valid target        |
| #Flat-Check    | Resolves via flat check rather than attack roll          |
| #Creature      | Can target living creatures                              |
| #Object        | Can target inanimate objects                             |
| #Self          | Targets or can target the caster                         |
| #Damage        | Deals direct damage                                      |
| #Persistent    | Applies persistent damage or an ongoing repeating effect |
| #Condition     | Applies a named condition                                |
| #Heal          | Restores HP or LP                                        |
| #Control       | Repositions, restricts, or alters movement               |
| #Summon        | Creates or animates an entity under your control         |
| #Medium-Solid  | Must travel through solid material to reach target       |
| #Medium-Liquid | Must travel through liquid to reach target               |
| #Medium-Air    | Requires open air medium (default for most manifolds)    |
| #Medium-Free   | No medium restriction                                    |
| #Contested     | Target actively resists via their own stat or roll       |

### Feat Tag System

| Tag          | Meaning                                    |
| ------------ | ------------------------------------------ |
| #feat        | Always present on all feats                |
| #maxem       | Class tag                                  |
| #core        | Fundamental feats all Maxems interact with |
| #weave       | Modifies how weaves work                   |
| #manifold    | Grants or modifies manifolds               |
| #counterwork | Counter-evoke and disruption feats         |
| #element     | Element-specific feat                      |
| #anchors     | Modifies anchor requirements               |
| #tempo       | Timing, AP, or action economy              |
| #economy     | MP cost modification                       |
| #power       | Output or damage enhancement               |
| #stealth     | Reduces tells, residue, or detection       |
| #reaction    | Grants or modifies reactions               |
| #geometry    | Area, shape, targeting modification        |
| #risk        | Weaves or effects with potential backlash  |
| #repeatable  | Can be taken multiple times                |
| #active      | Grants an action or reaction               |
| #passive     | Always-on effect                           |
