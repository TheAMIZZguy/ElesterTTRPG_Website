This is a TTRPG Ruleset that I am working on to fit my setting (Elester) that I started after realizing that I was homebrewing so many things to do so, that I should just create my own.

This is hosted in GitHub and make with Obsidian with the following plugins:
* Advanced Tables
* CustomJS
* Dataview
* Dice Roller
* Fantasy Statblocks
* Git
* Initiative Tracker
* Leaflet

The idea is that anyone can view online to learn all the rules, or download/fork to use themselves as a player or GM with built-in functionality for both. The core idea behind this ruleset is flexible characters, which implies that players can make contributions to new items, spells, feats, etc. and git gives that functionality with issues and pull requests. Get gaming!
